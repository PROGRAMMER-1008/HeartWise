# Model card

Intended audience: researchers, students and reviewers of a small explainable-classification demo. Not for diagnosis, treatment, screening, children or future event forecasting. Target: disease present (`UCI num > 0`) in the source dataset.

Artifact `hw-8f3c351bc5ead288` serves logistic regression C=0.1 with sigmoid calibration. Preprocessing standardizes numeric fields and encodes explicit categories; it is fitted only within training folds. `CalibratedClassifierCV(ensemble=False)` obtains training OOF scores for its calibrator and refits the base pipeline on its training portion. See [scikit-learn calibration documentation](https://scikit-learn.org/1.8/modules/generated/sklearn.calibration.CalibratedClassifierCV.html).

Selection objective was lowest development OOF Brier, then highest ROC-AUC, then lexical candidate identity for exact ties. Eight bounded configurations span logistic regression (C .1/1/10), tree, forest, XGBoost, SVM and KNN; each compares no calibration and sigmoid. No clinical utility claim attaches to this objective. Isotonic was not included: small calibration sets make it an overfitting concern. There are no correlation-derived monotonic constraints. Seed/config/split/code/dependency identities are saved in the manifest; no Git revision existed in the supplied folder.

Three nested development folds evaluate the selection procedure. The final candidate comparison uses five-fold OOF predictions on development data; its ranking scores are optimistic selection evidence. Fold SD is dispersion, not a confidence interval. The final test is internal retrospective data that was already inspected in earlier work; a new evaluation design does not turn it into an independent external benchmark.

Small groups and historical representation prevent fairness conclusions. The audited external hospitals lack enough complete compatible inputs, so external performance remains unestablished.

Explanations target the final served probability, using 16 fixed-seed permutation Shapley paths and eight development-background records. Each step replaces a full raw field, so no one-hot attribution is dropped. Each path telescopes from background mean to the patient score. All 13 grouped estimates, actual values, base value, output scale, target ID, top-five residual and reconstruction error are returned. Finite permutations approximate allocations, while reconstruction is exact within numerical tolerance. Correlated-feature hybrids may be unrealistic; contributions are model associations, not intervention effects. Failures appear as unavailable explanations without hiding successful predictions.
